# 多面展墙投影映射工作台

把一份连续视觉内容映射到具有夹角的多面展墙，为多台虚拟投影机生成**真实可投影的像素输出**，
并用一台一致的虚拟模拟相机重建墙面画面，检查墙角连续性、重叠融合带与接缝亮度。

所有墙面 / 投影机 / 内容坐标之间的变换均由针孔相机模型与射线求交**真实计算**，
不是把同一段视频等宽切片。无实体设备时，模拟相机生成的就是可用于核验的像素画面。

## 图形入口（主要使用方式）

直接用浏览器打开（无需构建、无第三方运行时依赖）：

```
index.html
```

或启动零依赖静态服务器：

```bash
npm run serve        # 然后访问 http://localhost:8080/
```

界面三区布局：

| 区域 | 内容 |
| --- | --- |
| 左栏 | 俯视几何标定（拖动墙面角点 / 投影机 / 目标点）、墙面与投影机参数、融合与编码设置、相机与内容、空间音画开关 |
| 中栏 | 各投影机实际输出图（蓝灰=投影范围外/被遮挡）、扭曲校正网格预览与导出 |
| 右栏 | 模拟相机重建合成图、覆盖率/重建误差/标定残差统计、接缝亮度剖面、报告导出 |

可调整的几何与融合项：

- 墙面：拖动共享角点改变折线夹角与墙长，墙高数值可调；角点被相邻墙面共享，折线始终连续
- 投影机：俯视拖动机位与目标点，或在表单精确编辑位置、目标、视场角、总增益与 RGB 通道增益（颜色补偿）
- 融合：四边羽化带宽度、融合曲线指数
- 显示：显示编码 gamma、测试图案（格线+渐变 / 纯格线 / 平滑渐变 / 棋盘格）
- 模拟相机：机位、视点、视场角，保证与投影机使用同一套几何与编码约定

异常（零长度墙、机位与目标重合、补偿裁剪等）由界面红色横幅或统计卡片直接提示，不依赖控制台。

## 三个内置场景

1. **折角三墙 · 重叠融合（含位置偏差）**：默认场景，三面带夹角的墙、三台投影机、相邻重叠带；
   第 3 台处于错误安装位姿（黄色高亮）。点「一键校正偏差机」或直接拖动标定，观察标定残差与接缝变化。
2. **L 形墙角 · 墙角连续性**：检查连续内容在 90° 墙角处是否对齐、格线是否连续。
3. **平面双机 · 接缝亮度**：宽幅平面墙大重叠，专门看接缝有无叠加过亮或变暗。

## 计算原理（要点）

- **几何**：墙面为俯视折线（共享角点），每面墙有局部 UV；连续内容坐标按各墙长度累计，
  墙角两侧内容坐标严格相等。投影机/相机均为针孔模型，逐像素生成射线并与所有墙面求交，
  背面与被其它墙遮挡的命中被剔除。
- **投影输出**：投影机像素射线打墙 → 取得墙面内容坐标 → 采样线性光内容 → 应用通道增益 →
  做显示编码写出 RGBA。投影范围外与遮挡位置 `alpha=0`，界面以蓝灰明确标示。
- **重叠融合**：对每个墙面点，把可见投影机的羽化权重 `w_k` 归一为 `w_k / Σw`，
  加权**在线性光空间**完成，因此任意重叠点数机贡献之和恒为 1，接缝不会叠加过亮；
  融合曲线指数只改变权重曲线，不改变处理空间。显示 gamma 只在最后编码时作用一次。
- **颜色补偿与裁剪**：RGB 增益超过显示范围会产生裁剪，界面给出裁剪像素数与提示。
- **验证指标**：墙面口径覆盖率、未覆盖像素、线性光平均/接缝重建误差、
  标定残差（各机实际命中世界点反投到相机像素的偏差）。

## 导出内容

- 每台投影机的输出 PNG（真实投影像素）
- 每台投影机的扭曲校正网格 PNG
- 每台投影机的校正网格 JSON（墙面 UV → 世界坐标 → 投影机像素，含是否在画面内标记）
- 模拟相机合成 PNG
- 汇总报告 JSON（几何、增益、羽化、覆盖率、误差、标定残差）

## 命令行（仅辅助批量导出与自动验证）

图形界面是主入口；CLI 用于无头批量渲染和数值自检：

```bash
npm run selftest
# 等价于:
node cli/mpm-cli.js --selftest

# 批量导出某场景的全部投影输出/校正网格/合成图/报告
node cli/mpm-cli.js --preset folded --out ./mpm-out --quality standard
node cli/mpm-cli.js --preset folded --aligned --out ./mpm-aligned   # 校正位姿对照
node cli/mpm-cli.js --preset lcorner|flat --pattern grid --gamma 2.2
```

`--help` 查看全部参数。CLI 与浏览器共用 `src/` 下同一套 UMD 模块和同一个零依赖 PNG 编码器。

## 测试

```bash
npm run selftest     # 13 项数值自检: 几何往返、内容连续、融合归一、无过亮、遮挡、偏差检出
npm run uitest       # 24 项界面测试 (jsdom): 交互、异常提示、导出、状态同步
```

## 目录结构

```
index.html            图形工作台入口
src/                  浏览器与 CLI 共享的零依赖核心 (UMD)
  vecmath.js          向量/正交基
  scene.js            多面墙、内容坐标、射线求交、遮挡判定
  projector.js        针孔投影机/相机、像素射线、羽化权重
  content.js          测试图案、线性光采样与显示编码
  render.js           几何缓冲、投影输出、模拟相机合成、校正网格
  png.js              零依赖 PNG 编码器
  presets.js          三个内置场景与渲染质量
web/                  界面层 (俯视编辑器、空间音画、主应用)
cli/mpm-cli.js        命令行辅助工具
tools/                静态服务器与界面测试
```

## 空间音画视窗

在「相机/内容」页开启后，于模拟相机画面移动指针：立体声像随墙面水平位置移动，
音量随该位置的重建线性亮度变化，音高沿墙位置微调，形成可听的空间对位反馈。
浏览器不支持 Web Audio 时由界面提示，不影响投影功能。
